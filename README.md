# 황희찬 역전골 xT

2022 월드컵 대한민국 2:1 포르투갈, 황희찬 역전골 장면에서 위협(xT)이 어떻게 커졌는지 재구성한 영상을 골라 보는 페이지. xT 표 12개(분할 4 × 모델 3, T 10초) 각각의 영상(`v/<분할>_<모델>.mp4`)과 12개를 한 화면에서 비교하는 영상(`all.mp4`).

- xT 표: 2026 기초 R&E 연구 (StatsBomb Open Data 2015/16 시즌 971경기로 학습)
- 경기 기록: StatsBomb Open Data, 2022 FIFA 월드컵 경기 3857262
- 선수·공 위치: 경기 하이라이트 영상에서 직접 추적 (실제 중계 화면이 아니라 재구성)
- 화면: 직접 만든 축구 게임 「킥오프 일레븐」의 렌더러
